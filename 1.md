# 1.1. Bikin HRD Merinding

Raka lulusan manajemen. Keahlian teknis tertingginya VLOOKUP, dan itu pun ia masih sering lupa mengunci tanda dolar. Jadi setelah enam bulan menganggur, ia melakukan hal yang wajar dilakukan orang putus asa: meminta SITI menyulap CV-nya.

"Ubah jadi Senior AI & Cloud Architect, lima tahun di Silicon Valley," ketiknya. "Bikin HRD merinding."

Tiga detik kemudian, lahirlah Raka versi baru. Raka yang ini pernah memimpin migrasi *multi-cloud*, menurunkan latensi sebesar 340%, dan fasih Python, meski satu-satunya python yang pernah ia lihat tinggal di Ragunan.

CV itu bekerja terlalu baik. Seminggu kemudian, sebuah startup memanggilnya wawancara. Raka memasang layar kedua di belakang kamera, tersambung ke SITI. Ketika manajer IT bertanya cara menangani *bottleneck* pada *distributed cache* saat trafik naik sepuluh kali lipat, Raka cukup mengusap dagu, melirik layar, lalu membaca dengan suara paling berwibawa: "*Consistent hashing*, *cache-aside*, dan *rate limiting* di API gateway."

Manajer IT terperangah. Raka juga, karena ia tidak paham satu kata pun. Senin berikutnya, ia resmi menjadi Lead System Architect.

Sayangnya, hari pertama datang bersama kebijakan baru: WFO penuh, tanpa layar kedua, Wi-Fi kantor memblokir semua situs AI, dan ruangannya di *basement* tanpa sinyal. Untuk pertama kalinya, Raka harus bekerja tanpa SITI.

Pukul sembilan pagi, manajer IT menghampirinya. "Bro, cek *memory leak* di server *staging* ya. Akses root udah gue email."

Raka menatap terminal hitam yang berkedip, lalu mengetik satu-satunya perintah Linux yang ia ingat dari TikTok semalam:

```bash
sudo rm -rf / --no-preserve-root
```

Jarinya baru melayang di atas Enter ketika manajer IT melongok dari belakang, dan wajahnya langsung pucat. "B-Bro... lu mau *reset* total dari akar?"

"I-iya," jawab Raka, mencomot *caption* video motivasi yang lewat semalam. "Kadang, untuk menyembuhkan sistem, kita harus menghancurkannya dulu."

"GILA! Ini baru arsitek Silicon Valley!" Saking kagumnya, manajer IT menepuk bahu Raka keras-keras, dan jempol Raka mendarat tepat di Enter.

Terminal menggulung ribuan baris, lalu diam. Manajer IT membuka dashboard, dan matanya berbinar. "Memory nol persen! Error nol! CPU nol! *Leak*-nya hilang total!"

Seisi ruangan bertepuk tangan. Raka ikut tersenyum, karena semua itu memang benar: tidak ada *leak*, tidak ada error, dan tidak ada apa-apa lagi di server itu. Untungnya, itu cuma *staging*.

Siang harinya, manajer IT mampir lagi dengan wajah sumringah. "Bro, server produksi juga ada *leak*. Abis makan siang, lu jalanin *command* yang sama di sana ya. Direksi mau nonton langsung."

Untuk pertama kalinya hari itu, giliran Raka yang pucat.

Lima menit kemudian, Raka sudah berdiri di parkiran, satu-satunya tempat yang ada sinyal. Dengan jari gemetar, ia membuka SITI dan mengetik:

"Cara resign baik-baik gimana? Kali ini jangan bikin HRD merinding."
